# GP. Dashboard for Vest

![GP. Dashboard](preview.png)

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/)
2. **[Install GP. Dashboard](https://raw.githubusercontent.com/deciphe/gp-vest/main/gp-vest.user.js)**
3. Open Vest → Affiliates or Portfolio → **GP. Dashboard**

Updates install automatically.
